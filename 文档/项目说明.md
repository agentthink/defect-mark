# MaskFlow 项目说明

MaskFlow 是一个面向图像数据集的 AI 自动标注平台，包含 Vue 前端、ASP.NET Core 业务 API、Python SAM 推理服务，以及原型图和模型资源。

## 目录结构

```text
src/
  frontend/maskflow-web/       Vue 3 + Vite 前端
  backend/maskflow-api/        ASP.NET Core WebAPI 后端
  ai/sam-inference/            Python GPU 推理服务
  legacy/                      旧版代码备份

文档/
  项目说明.md
  修改记录.md
  产品设计/

资源/
  模型/sam3.pt
  原型图/

docker-compose.yml             Docker 编排入口
.env.example                   环境变量模板（复制为 .env）
.gitignore                     忽略规则
```

## 本地开发

业务 API：

```powershell
dotnet run --project src\backend\maskflow-api\MaskFlow.Api.csproj --urls http://127.0.0.1:8010
```

前端：

```powershell
cd src\frontend\maskflow-web
npm install
npm run dev -- --host 127.0.0.1 --port 3010
```

SAM 推理服务：

```powershell
cd src\ai\sam-inference
python -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

## Docker 部署

1. 复制环境变量：`copy .env.example .env`，按本机修改密码、路径与端口。
2. 确保模型文件存在：`资源/模型/sam3.pt`。
3. 启动：

```powershell
# 全量启动
docker compose up -d --build

# 常见增量更新
docker compose up -d --build api web
docker compose up -d --build sam-inference
docker compose up -d --build api web sam-inference
```

| 服务 | 地址 |
|------|------|
| 前端 | http://127.0.0.1:3000 |
| API / Swagger | http://127.0.0.1:8000/swagger |
| SAM | http://127.0.0.1:8001 |

### 与本版本相关的部署注意点

- **忘记密码**：默认不发邮件。`ASPNETCORE_ENVIRONMENT=Development` 或 `MASKFLOW_PASSWORD_RESET_INLINE=true` 时，接口会回显重置码，前端可直接完成找回。
- **分割边缘平滑 / 点提示**：改动在 `sam-inference`，发版需重建该容器后重新推理。
- **标注画布缩放**：纯前端改动，重建 `web` 后强制刷新浏览器即可。
- 更多环境变量说明见根目录 [`README.md`](../README.md) 与 [`.env.example`](../.env.example)。
- 变更明细见 [`修改记录.md`](修改记录.md)。
