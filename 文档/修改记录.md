# MaskFlow 修改记录

## 2026-09-07 导出分析与六项审查修复

- 导出页新增数据集分析：展示项目原图数、参与划分原图数、目标数量、待确认数量、每类目标占比和原图占比，以及当前和建议划分的预计分布。
- 新增只读接口 `POST /api/export/analyze`，使用与真实导出相同的类别映射、筛选及划分规则，按登录用户隔离项目数据。
- 推荐比例采用公开的启发式规则，依据最少类别的原图数：不足 2 张时仅训练并建议先补样；2–14 张为 80/20/0；15–49 张为 60/20/20；50–99 张为 70/20/10；100 张及以上为 80/10/10。页面提供一键应用，说明建议未经过模型训练验证，不代表最优比例。
- 补样参考目标为每类至少 `max(30, ceil(最多类别原图数 / 3))` 张原图；显示各类差额，提醒优先补充不同批次、光照、角度及困难场景，而非重复裁剪。缺类别、未标注图片、未分配类别及未人工确认目标均有提示。
- 修复快速切图请求乱序：预览、标注和保存/AI 响应校验当前图片及选择版本，图片加载完成前禁止编辑与保存；过期的项目文件/标签响应不再覆盖新项目。
- 修复分割导出混入矩形检测行：缺失、退化或无效轮廓阻止分割导出，提示补充分割或选择检测格式；矩形仍可保存供检测使用。
- 修复导出类别编号错位：分析与导出共享最终类别表，重新映射 ClassId 和规范类别名，不改动原始标注；覆盖跨项目及类别重排序。
- 修复 SAM Docker 构建依赖未跟踪缓存目录：改用构建上下文只读挂载，缓存权重存在则使用、不存在则走原下载重试流程，不再强制 COPY 可选目录。
- 修复保存自动确认所有目标：保留逐条人工确认状态，取消确认后保存不会被重新确认。
- 修复宽高比筛选：按原图像素尺寸计算目标宽高比；当前图片预览、全项目统计与删除共用相同规则，尺寸未知时不执行宽高比匹配。
- 增加后端推荐、统计、权限隔离和分割校验测试；增加前端格式/筛选单元测试，以及切图竞态、确认保存、全项目筛选删除、导出建议应用、错误状态和桌面/手机布局浏览器回归脚本。
- 验证结果：47 项后端测试、3 项前端单元测试通过；浏览器回归使用隔离的模拟数据，覆盖上述交互与桌面/手机布局，不修改真实项目。浏览器脚本需外部 Playwright 和 Chrome，可通过 `PLAYWRIGHT_MODULE` 指定模块路径、`TEST_BASE_URL` 指定本地前端地址。
- 前后端已重新构建并更新到本机 Docker，页面和 `/api/status` 健康检查通过；SAM、MySQL、MinIO 保持原容器运行。SAM Dockerfile 已完成构建规则检查（存在布尔配置名被识别为密钥的既有告警），本次未完整重建 GPU 推理镜像。

## 2026-09-07 数据集分层随机划分

- 检测、分割和分类裁剪导出统一采用按原图分组的多标签分层随机划分，替代按上传顺序或裁剪顺序切分。
- 先统计每类的原图数与标注目标数，优先分配稀有类别，并兼顾目标数量和整体图片比例；背景图片按剩余图片配额分配。
- 同一原图及其全部分类裁剪始终属于一个集合，避免同源裁剪跨训练、验证、测试集。暂不识别不同文件之间的近重复图片或同一拍摄对象。
- 保留用户配置比例与默认 70/20/10。类别样本充足时尽量覆盖三个集合；不足时优先训练集，其次验证集，并在报告中提示缺样。多标签共现与原图不可拆分时，实际比例可能偏离目标比例，不保证固定比例能获得最佳泛化效果。
- 导出接口新增可选 Seed 参数，默认 42；数据、比例与种子相同时划分可复现，修改种子可重新随机划分。
- ZIP 新增 split-report.json，记录每类目标数、图片数、各集合分布、原图分配清单及类别缺样提示。
- 按导出最终类别表重新映射 ClassId，修复跨项目类别编号冲突；data.yaml 类别名使用安全引号输出。
- 校验各集合比例必须在 0 到 100 之间且总和为 100；增加分层算法及三种格式实际 ZIP 导出回归测试。

- 正式采用 AGPL-3.0，并补充第三方组件与 SAM 3 模型权重声明。
- 重写 README 首屏，加入点提示分割、控制台、图片管理和数据集导出截图。
- 修复 Production 模式示例密钥可通过校验的问题，禁止生产环境开启重置码回显和计费开发模式。
- SAM 内部鉴权改用常量时间比较；注册和修改密码统一要求至少 8 个字符。
- Docker Compose 默认仅绑定回环地址，MySQL/API 数据卷改为首次启动自动创建。
- SAM 服务默认启用内部密钥，Compose 增加健康检查，前端镜像改用 `npm ci`。
- 新增前后端 `.dockerignore`、GitHub Actions CI 和 Dependabot 配置。

## 2026-08-21

### 1. 忘记密码 / 密码找回

**问题**：登录页「忘记密码？」为无效链接，点击无反应。

**改动**：
- 前端登录页增加「获取重置码 → 设置新密码」完整流程（`AuthPage.vue`、`useMaskFlowApp.js`）
- 后端新增接口：
  - `POST /api/auth/forgot-password`：按邮箱生成 30 分钟有效重置码
  - `POST /api/auth/reset-password`：用重置码设置新密码并失效旧会话
- 当前部署未接邮件服务，开发环境 / `MASKFLOW_PASSWORD_RESET_INLINE=true` 时在页面内回显重置码
- `docker-compose.yml` 默认开启 `MASKFLOW_PASSWORD_RESET_INLINE=true`

### 2. 点提示（Point Prompt）SAM 分割

**能力**：在自动分割页与标注页支持正/负点击提示抠图。

**改动**：
- SAM 服务新增 `POST /api/segment/points`（`sam-inference`）
- API 代理：`/api/segment/points`、`/api/annotations/points`
- 前端共用点提示状态与请求逻辑；确认目标后保留多边形/框，清除提示点；可新建下一目标
- 检测类项目仍可同时保存 bbox + mask
- 推理侧修复：点坐标按「单目标多点」组织、掩码类型转换、请求串行化等稳定性问题

### 3. 分割边缘平滑

**问题**：掩膜边缘锯齿明显，圆形等目标贴边不干净。

**改动**（`sam-inference`）：
- 掩膜升采样改为三次插值 + 高斯软边
- 椭圆核形态学闭运算/开运算修边
- 轮廓点滑动平均后再轻度多边形简化
- 叠加预览与导出几何共用同一套精炼逻辑

### 4. 标注画布缩放修复

**问题**：缩放比例超过 100% 后画面不再变大（看起来只能放到适配尺寸）。

**改动**：
- 去掉画布 `max-width/max-height: 100%` 对显式缩放尺寸的限制
- 放大后可在画布区域内滚动查看
- 缩放范围仍为 25%–300%；「适配」回到窗口适合尺寸
